# ai_melli — تولید تصویر و متن روی GitHub Actions

بدون API Key و بدون سرور: پس از Fork، از تب Actions اجرا می‌کنی و نتیجه
به‌صورت فایل در ریپو ذخیره می‌شود.

## اجرا از تب Actions

1. Fork کن.
2. `Actions → AI Generate → Run workflow`.
3. ورودی‌ها را پر کن:
   - `mode`: `text` یا `image`
   - `prompt`: پرامپت (فارسی یا انگلیسی)
   - `smart`: برای تصویر — اگر روشن باشد، پرامپت فارسی خودکار بهبود می‌یابد
   - `model`, `temperature`, `system_message` برای متن
4. پس از اجرا، فایل‌ها در `ai/output/` ذخیره می‌شوند و گالری به‌روز می‌شود.

## اجرای محلی

```bash
python3 ai/generate.py --selftest
python3 ai/generate.py --mode text  --prompt "درباره تمدن نوین اسلامی بنویس" --out ./ai/output
python3 ai/generate.py --mode image --prompt "کتابخانه‌ای در غروب" --smart --out ./ai/output
python3 ai/gallery.py --dir ./ai/output
```

## حالت آفلاین

* **متن**: اگر سرویس بیرونی در دسترس نباشد، یک تولیدکننده‌ی محلی الگویی خروجی
  ساختاریافته می‌دهد تا جریان کار کامل بماند.
* **تصویر**: اگر سرویس تصویر در دسترس نباشد، یک تصویر SVG برداری با همان
  پرامپت ساخته می‌شود تا گالری و مسیر ذخیره‌سازی کامل تست‌پذیر بماند.

این یعنی می‌توانی کل خط تولید، گالری و کامیت خودکار را بدون هیچ سرویس بیرونی امتحان کنی.

## بهبود پرامپت فارسی (smart)

`prompt_enhancer.py` پرامپت فارسی را تحلیل و به انگلیسی با جزئیات نورپردازی،
سبک و ترکیب‌بندی تبدیل می‌کند. واژه‌نامه‌ی موضوعی داخل خودش است و آفلاین کار می‌کند.

## تنظیم سرویس بیرونی (اختیاری)

| متغیر | کاربرد |
|-------|--------|
| `OPENAI_BASE_URL` + `OPENAI_API_KEY` | تولید متن با مدل بیرونی سازگار با OpenAI |
| `IMAGE_API_URL` + `IMAGE_API_KEY` | تولید تصویر با سرویس بیرونی |

اگر تنظیم نشوند، همان مسیر محلی اجرا می‌شود. هیچ کلیدی داخل ریپو نوشته نمی‌شود؛
از GitHub Secrets استفاده کن.
