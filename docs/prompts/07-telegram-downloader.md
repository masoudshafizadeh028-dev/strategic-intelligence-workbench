# 07 — دانلود تلگرام

از لینک پستی که صاحب نشست مجاز به دیدنش است فایل را دریافت کن. نام فارسی به UUID ASCII + پسوند امن تبدیل شود. فایل بزرگ را قطعات حداکثر ۹۰ MiB کن و manifest/checksum بساز. اعتبارنامه فقط GitHub Secrets؛ هیچ‌گاه log/commit نشود. workflow لینک را از ورودی بگیرد، artifact تولید کند و commit تنها با اختیار صریح. به حق نشر و مجوز دسترسی احترام بگذار.
