# 03 — مولد صفحه‌ی اندیشکده

صفحه‌ای فارسی RTL، تیره، واکنش‌گرا و آفلاین بساز: معرفی، مأموریت، محورها، نقشه‌ی SVG تعاملی، جست‌وجوی سریع، roadmap فیلترشونده، پیشرفت localStorage و مسیر توسعه. HTML معنایی، دسترسی صفحه‌کلید، reduced motion، کنتراست، مسیرهای نسبی، robots.txt، sitemap.xml و SEO را رعایت کن. پیشرفت فقط محلی باشد و پاک‌کردن/خروجی JSON داشته باشد.
