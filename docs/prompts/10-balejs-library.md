# 10 — balejs TypeScript

BotClient و UserClient جدا؛ HTTP transport، timeout/retry/backoff, polling، command/message/callback. پیام، edit/delete/forward/copy، عکس/سند، فاکتور و pre-checkout فقط براساس API مستند. نشست کاربر از adapter تزریقی با protocol مستند؛ endpoint حدسی ممنوع. گروه/wallet اگر پشتیبانی تأیید نشده `unsupported` بده. مثال echo/session و selftest با fetch جعلی.
