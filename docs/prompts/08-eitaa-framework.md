# 08 — چارچوب ربات ایتا

Python framework: transport جدا، plugin handler، settings از env، logging بدون راز و selftest آفلاین. قرارداد adapter باید مستند باشد؛ endpoint را حدس نزن. ورودی نرمال‌شده chat_id/user_id/text/update_id. نمونه /start, /help, سلام و demo بگذار؛ اگر API رسمی در دسترس نیست، اجرا را demo/adapter-configured اعلام کن.
