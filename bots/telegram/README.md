# TelegramDownloader

دانلود خودکار فایل از پست‌های تلگرام و ذخیره در پوشه‌ی `downloads/`.
پس از یک‌بار تنظیم، فقط لینک پست را می‌دهی و بقیه خودکار انجام می‌شود.

## راه‌اندازی یک‌باره

1. **مخزن را فورک کن** (یا از این مخزن استفاده کن).
2. در `Settings → Secrets and variables → Actions` یک Secret بساز:
   - `TG_SESSION` — رشته‌ی نشست Telethon (نه توکن ربات).
3. تمام. از تب **Actions** ورک‌فلو `Telegram Download` را انتخاب کن،
   `Run workflow` را بزن، لینک پست را بچسبان و اجرا کن.

## اجرای محلی

```bash
pip install -r requirements.txt

# یک‌بار ورود تعاملی و ساخت نشست
python3 downloader.py --login --api-id 123456 --api-hash abcdef0123456789

# دانلود از لینک
python3 downloader.py --link https://t.me/channel/123 --out ./downloads

# خودآزمایی بدون شبکه
python3 downloader.py --selftest
```

`api_id` و `api_hash` را از <https://my.telegram.org> بگیر (رایگان).

## پشتیبانی فایل‌ها

| نوع | پسوندها |
|-----|---------|
| عکس | `.jpg` `.png` `.webp` |
| ویدیو | `.mp4` `.mkv` `.mov` |
| صوت | `.mp3` `.ogg` `.m4a` |
| سند | `.pdf` `.zip` `.rar` `.docx` `.epub` |
| سایر | هر فایل بدون پیش‌نمایش |

فایل‌های با نام فارسی به‌طور خودکار نام انگلیسی تصادفی می‌گیرند
(`uuid4` + پسوند اصلی) تا روی گیت‌هاب مشکلی نباشد.

## تقسیم فایل بزرگ

اگر حجم فایل از `split_threshold_mb` (پیش‌فرض ۹۰) بیشتر باشد،
به قطعات ۹۰ مگابایتی تقسیم و همراه `manifest.json` ذخیره می‌شود.
محدودیت ۱۰۰ مگابایتی گیت‌هاب برای هر فایل رعایت می‌شود.

## محدودیت‌ها

- دانلود از کانال‌های **عمومی** و پست‌های در دسترسِ حساب خودت.
- محتوای دارای حق نشر را فقط با اجازه دانلود کن.
- نشست تلگرام یک اعتبار حساس است؛ هرگز آن را کامیت نکن.
