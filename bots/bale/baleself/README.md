# baleself — سلف‌بات بله با Selenium

ربات شخصی برای پیام‌رسان بله که با مرورگر واقعی وارد حساب خودت می‌شود،
به پیام‌های مشخص پاسخ می‌دهد و به دستور «داپش بهم بگو ...» متن تولید می‌کند.

## نصب

```bash
pip install -r requirements.txt
# Selenium Manager خودش درایور Chrome را می‌گیرد (نیازمند اینترنت در اولین اجرا)
```

## اجرا

```bash
python3 main.py --selftest      # آزمون منطق بدون مرورگر
python3 main.py --demo          # شبیه‌سازی پردازش پیام
python3 main.py                 # اجرای واقعی (مرورگر + ورود دستی/QR)
```

## افزودن دستور

در `baleself/rules.py` یک قاعده با دکوراتور `@rule` ثبت کن:

```python
@rule(r"^ساعت چند است\?")
def clock(ctx):
    return ctx.reply("ساعت را از ساعت سیستم بپرس :)")
```

## نکات مهم

- ورود با **حساب خودت**؛ نشست در پوشه‌ی `./.bale-profile` ذخیره می‌شود تا ورود بعدی ساده باشد.
- هرگز نشست/رمز را کامیت نکن. پوشه‌ی پروفایل در `.gitignore` است.
- سلف‌بات‌ها ممکن است با شرایط استفاده‌ی سرویس در تنش باشند؛ مسئولیت استفاده بر عهده‌ی توست.
- selectorها با تغییر رابط بله ممکن است عوض شوند؛ همه در `baleself/selectors.py` متمرکز شده‌اند.
